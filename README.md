# hubspot-lab3

Лабораторная работа №3 по маркетингу. Продукт — HubSpot. Сайт, креативы, поисковые объявления и материалы для сдачи — на русском языке.

- [Сайт](https://indolentmenace.github.io/hubspot-lab3/)
- [Материалы для сдачи](https://indolentmenace.github.io/hubspot-lab3/materials.html)
- [Баннер, карусель, видео и исходники](https://indolentmenace.github.io/hubspot-lab3/creative-studio.html)

## Комплект

Отчёт по четырём этапам (Word и PDF), презентация (PowerPoint и PDF), сайт и статичный баннер, карусель из трёх карточек (PNG/SVG) и видеоролик (MP4, 15 секунд). Дополнительные расчёты включены в сам отчёт.

## Аналитика

Рабочая версия по данным от 10.11.2026: GA4 — 5 сеансов, начало и завершение демо — по 4, начало формы — 4, заявка — 3; Метрика — 14 визитов в предоставленном обзоре. Автор подтвердила период GA4 9–10 ноября и отбор lab3_pilot в Метрике. В Метрике: начало демо — 8 целевых визитов, завершение — 6, начало формы — 7, заявка — 6. Три метрики рассчитаны на единой базе Метрики: 42,86%, 75%, 85,71%. Сценарий одной дополнительной заявки — 50% конверсии (+7,14 п.п.). В приложениях отчёта подготовлены пять подписанных мест для скриншотов; на слайде 8 — места для двух основных снимков. Перед сдачей рамки заменяются изображениями. Подключены GA4 `G-G3VYMYNQYY` и Метрика `114146329`.

События: `demo_start`, `demo_complete`, `request_start`, `demo_request`. Дополнительно учитываются нажатия кнопок и шаги демонстрации. Ключевое действие — учебная заявка; она не создаёт настоящий аккаунт HubSpot или встречу. Счётчики включаются после согласия; значения полей формы не передаются.

GitHub Pages: ветка `main`, каталог `/`. Сборка не требуется.

## Создание креативов

Баннер и карточки: код на [Python](https://www.python.org/) и отрисовка PNG с [Pillow](https://python-pillow.github.io/); SVG сформирован тем же кодом. Видео: кадры Python/Pillow, сборка и кодирование MP4 через [FFmpeg](https://ffmpeg.org/). GitHub используется для хранения исходников и публикации файлов.
