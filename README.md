# hubspot-lab3

HubSpot — лабораторная работа №3

Независимый учебный проект по performance-аналитике. Сайт не является официальным сайтом HubSpot и не создаёт реальные аккаунты или заявки в HubSpot.

- Сайт: https://indolentmenace.github.io/hubspot-lab3/
- Материалы: https://indolentmenace.github.io/hubspot-lab3/materials.html
- Редактор креативов: https://indolentmenace.github.io/hubspot-lab3/creative-studio.html

## Статус

Подготовлены сайт, рекламный план, креативы, рабочий отчёт, расчётная книга, инструкция и презентация. Реальные счётчики пока не подключены: идентификаторы в `config.js` пустые. Фактические данные и скриншоты должны быть получены после настройки GA4 и Яндекс Метрики и апробации на участниках. Никакие расчётные примеры не выдаются за реальные наблюдения.

## Подключение

В `config.js` указать публичный Measurement ID GA4 и числовой номер счётчика Метрики. Не добавлять пароли, OAuth-токены или секреты. Счётчики загружаются только после согласия посетителя.

События: `cta_click`, `demo_start`, `demo_step`, `demo_complete`, `request_start`, `demo_request`. Форма не собирает контактные данные; её значения не отправляются аналитическим сервисам. Вебвизор выключен. В GA4 пометить `demo_request` как ключевое событие; в Метрике создать соответствующие цели.

## Публикация

GitHub Pages: ветка `main`, корень `/`. Сборка не требуется. Все локальные ссылки относительные, поэтому сайт работает в подпапке репозитория.

## Проверка

Проверены синтаксис JavaScript, локальные ссылки, логика согласия, отправка одинаковых событий в заглушки двух систем, отсутствие передачи значений формы и границы текста PDF. Реальную приёмку событий в аккаунтах выполнить после получения ID. Браузерная визуальная проверка в рабочей среде не выполнялась: инструмент общего браузера не предоставлен.

## Файлы

`materials/` — DOCX/PDF, PPTX/PDF, XLSX и ZIP-комплект. `creatives/` — оригинальные SVG и PNG. `creative-studio.html` позволяет редактировать заголовки и экспортировать SVG в браузере.
