# hubspot-lab3

Лабораторная работа №3 по маркетингу. Продукт — HubSpot. Сайт, креативы, поисковые объявления и материалы для сдачи — на русском языке.

- [Сайт](https://indolentmenace.github.io/hubspot-lab3/)
- [Материалы для сдачи](https://indolentmenace.github.io/hubspot-lab3/materials.html)
- [Баннер, карусель, видео и исходники](https://indolentmenace.github.io/hubspot-lab3/creative-studio.html)

## Комплект

Отчёт по четырём этапам (Word и PDF), презентация (PowerPoint и PDF), сайт и статичный баннер, карусель из трёх карточек (PNG/SVG) и видеоролик (MP4, 15 секунд). Дополнительные расчёты включены в сам отчёт.

## Аналитика

Рабочая версия по данным от 10.11.2026: GA4 — 5 сеансов и 3 сеанса с заявкой; Метрика — 14 визитов в предоставленном обзоре. Автор подтвердила период GA4 9–10 ноября и отбор lab3_pilot в Метрике. В документах указаны границы сравнения, расчёты и сценарный прогноз. Для сдачи нужны полные скриншоты и целевые визиты Метрики. Подключены GA4 `G-G3VYMYNQYY` и Метрика `114146329`.

События: `demo_start`, `demo_complete`, `request_start`, `demo_request`. Дополнительно учитываются нажатия кнопок и шаги демонстрации. Ключевое действие — учебная заявка; она не создаёт настоящий аккаунт HubSpot или встречу. Счётчики включаются после согласия; значения полей формы не передаются.

GitHub Pages: ветка `main`, каталог `/`. Сборка не требуется.
